## 정한 것 (사용자 2026-11-14 "추천대로 진행해") — 시안과 기존 결정이 부딪히는 곳
1. **샘플 리포트 "단원 이해도 70%"**: 리포트는 숫자 없이 단계만 보인다(`SCORING.md` 5절, `DESIGN.md` "리포트 표시"). 에이전트 추천: 넣지 않고 그 자리에 단원 단계 칩("기본 이해") + 3칸 단계 막대. 비교 영역의 "점수로 보면 70점"은 점수 방식의 예시라 그대로 둔다.
2. **"무료로 시작하기"**: 요금 정책을 정한 적이 없다. 에이전트 추천: "지금 시작하기".
3. **그림(노트북 속 화면, 개념이, 책, 리포트 아이콘)**: 래스터 그림을 만들 도구가 없다. (가) SVG·CSS로 비슷하게 그린다 — 노트북 화면 안은 실제 학습 지도 부품(노드·칩)을 작게 재사용, 개념이는 기존 `mascot.tsx` (나) 사용자가 그림 파일(PNG/SVG)을 주면 `public/`에 넣어 쓴다. 에이전트 추천: (가) 먼저, 마음에 안 들면 (나).
4. 단계 칩 이름: 시안 "아직 미이해" → 서비스 이름 "아직 이해 못 함"(`SCORING.md`)을 쓴다. (확인만)
