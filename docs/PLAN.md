## 결정 (에이전트 추천, 사용자 확인 필요)
1. **같은 단원 동시 시작 500 → 409.**
   - 원인: `diagnosis_start`(`supabase/migrations/20261110220000_create_diagnoses.sql`)는 진행 중 진단을 `for update`로 찾는다. 하지만 둘 다 아직 없을 때는 잠글 행이 없어서, 두 요청이 모두 넣기까지 간다. 그러면 유일 색인 `diagnoses_one_in_progress`(같은 파일 25줄)가 두 번째를 막고, 이 오류가 백엔드에서 500으로 나간다.
   - 추천: **백엔드만 고친다.** `POST /diagnoses`(`backend/app/diagnoses/router.py:203`)에서 DB 함수가 유일 색인 위반(Postgres `23505`)을 돌려주면, 진행 중 진단을 다시 읽어 기존과 같은 409 `{"code":"in_progress","diagnosis_id"}`를 돌려준다.
   - 이유: 마이그레이션이 없으므로 원격 DB를 바꾸지 않고, 배포 사이트도 깨지지 않는다(이어받은 것).
2. **TabList 콘솔 경고.**
   - 원인: Astryx `Tab`은 `role="tablist"`일 때 `panelId`가 없으면 경고한다(`@astryxdesign/core/dist/TabList/Tab.js:217`). 학습 지도 학년 탭(`frontend/src/app/(protected)/unit-selection.tsx:124`)에 `panelId`가 없다.
   - 고침: 학년별 단원 영역에 `id`와 `role="tabpanel"`을 주고, 각 탭에 `panelId`를 준다. 검색 중(탭 선택 없음)일 때의 동작은 그대로 둔다.
3. **그림 라벨 겹침 2건.** 라벨 배치 코드(`frontend/src/lib/figures/`)를 고친다.
   - 문제 5d7a72c7(`backend/data/bank/9수02-05.json`): 점이 축 가까이 있으면 점·이름이 눈금 숫자와 겹친다. `PROGRESS.md`에는 `9수01-02`로 잘못 적혀 있어서 함께 고친다.
   - 문제 29c04fca(`9수03-04`): 꼭짓점 이름이 다른 이름을 피하다가 도형 안쪽으로 들어간다.
   - **승인된 다른 그림이 바뀌지 않는지 확인한다.** 고치기 전과 후에 문제 은행의 모든 그림 라벨 위치를 계산해 비교하고, 바뀐 그림 목록을 사용자에게 보인다. 바뀐 그림은 330px·250px로 그려 확인한다.
   - 그림 데이터(DB)는 바꾸지 않는다.
4. **README** (저장소 첫 화면, 새 파일 `README.md`). 담을 것:
