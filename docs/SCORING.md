# SCORING

채점과 이해도 계산 기준이다 (F-07, F-08).
원칙: AI가 판단하는 곳은 **서술형 채점 요소 판단** 하나뿐이다. 그 뒤의 계산은 모두 정해진 식으로 한다. 같은 채점 결과를 넣으면 항상 같은 이해도가 나와야 한다 (`docs/features.md` F-07 완료 조건).

결정: 사용자 결정 (2026-11-09). 구간 경계값처럼 근거가 없는 값은 표시해 두고, 수학 교육 전문가 검토 때 다시 본다.

---

## 1. 문제 점수 (0~1)

| 유형 | 채점 방법 | 점수 | 함께 기록 |
|---|---|---|---|
| 객관식 | 코드로 정답 비교 (AI 사용 안 함) | 정답 1, 오답 0 | 고른 보기에 연결된 오개념 ID (일반 오답이면 없음) |
| 서술형 | AI가 채점 요소마다 **충족 / 미충족** 판단 | 충족한 요소 배점 합 ÷ 전체 배점 | 요소별 판단과 판단 근거, AI가 발견한 오개념 ID |

- 서술형 판단을 두 가지(충족/미충족)로만 하는 이유: 선택지가 적을수록 AI 판단이 덜 흔들릴 것으로 본다. (에이전트 추론, 연구 근거 없음)
- AI 채점 결과는 한 번 받아 저장한다. 다시 계산할 때 AI를 다시 부르지 않는다.

## 2. 일반 문제 통과 (2단계 진행 조건)

| 유형 | 통과 조건 |
|---|---|
| 객관식 | 정답 |
| 서술형 | 채점 요소 중 **필수** 요소를 모두 충족 (필수 여부는 문제의 채점 요소에 미리 표시) |

통과한 평가 항목만 2단계 고난이도 문제를 받는다 (F-05).

## 3. 평가 항목 점수 (0~1)

| 결과 | 점수 | 단계 이름 |
|---|---|---|
| 일반 문제 미통과 | 일반 점수 × 0.5 (객관식이면 0) | 아직 이해 못 함 |
| 일반 통과, 고난이도 미통과 | 0.5 + 고난이도 점수 × 0.5 (객관식이면 0.5) | 기본 이해 |
| 일반 통과, 고난이도 통과 | 1 | 깊이 이해 |
| 일반 통과, 고난이도 미응답 (2단계 도중 중단) | 0.5 | 기본 이해 + 리포트에 "심화 문제는 풀지 않음" 표시 |
| 일반 통과, 승인된 고난이도 문제가 없음 | 0.5 | 기본 이해 + 리포트에 "심화 문제는 아직 준비 중" 표시 (사용자 결정 2026-11-10) |
| 승인된 문제가 없어 제외 (F-05) | 측정 안 함 | — (평균에서 뺀다) |

- 2단계 미응답을 0.5로 두는 이유: 일반 문제 통과 사실은 남기고, 깊이 이해 여부는 측정하지 못했음을 표시한다. (사용자 결정, 2026-11-09)

## 4. 개념·단원 이해도

- 개념 이해도 = 그 개념의 평가 항목 점수 평균 (제외된 항목은 빼고 계산)
- 단원 이해도 = 개념 이해도의 평균
- 가중치는 모두 같다. 다르게 줄 근거가 없다.
- 개념의 평가 항목이 모두 제외되면 그 개념은 "측정 안 됨"으로 표시한다.

## 5. 학생에게 보여 주는 단계 (F-08)

숫자 대신 단계로 보여 준다.

| 이해도 | 단계 |
|---|---|
| 0.5 미만 | 아직 이해 못 함 |
| 0.5 이상 0.8 미만 | 기본 이해 |
| 0.8 이상 | 깊이 이해 |

- 경계값 0.5는 평가 항목 점수의 "기본 이해" 시작점과 맞춘 것이다.
- **경계값 0.8은 근거가 없다.** 전문가 검토 대상이다.

## 6. 추정 오개념 (F-08)

- 개념별로 모은다: 고른 객관식 오답 보기에 연결된 오개념 + 서술형 채점에서 AI가 발견한 오개념
- 리포트에서는 "~일 수 있어요"처럼 **추정**으로 표현한다. 한 번의 선택은 찍은 것일 수 있기 때문이다.
