## 목표
1단계 제출 뒤 진단이 **끝까지** 가게 한다.
1. 1단계를 제출하면 채점한다. 객관식은 코드로, 서술형은 AI로 채점한다 (F-07, `docs/SCORING.md` 1~2절).
2. 일반 문제를 통과한 평가 항목에 고난이도 문제를 내고(2단계), 풀고 제출하면 다시 채점한다 (F-05, F-06). 통과한 항목이 없으면 2단계 없이 끝난다.
3. 개념·단원 이해도와 추정 오개념을 계산한다 (`docs/SCORING.md` 3~6절).
4. AI가 리포트 문장을 쓰고, 화면에 리포트를 보여 준다 (F-08).
5. 채점 결과와 리포트를 저장한다. 다시 열면 AI를 다시 부르지 않는다 (F-09).

## 결정 사항 (사용자 결정, 2026-11-10: "전부 다 추천대로 진행하자")
아래 1~8의 **추천**을 모두 채택한다. 1단계에서 `docs/DESIGN.md`로 옮긴다.

1. **채점 시점과 AI 실패 처리**
   - 추천: 제출 요청 안에서 바로 채점한다. 서술형은 단계마다 0~1개라 AI 호출 1번, 약 4초다.
   - 추천: AI 호출이 실패하면 제출을 기록하지 않고 "잠시 후 다시 제출해 주세요"를 보인다. 답안은 그대로 남는다.
   - 채점 결과 저장, 제출 시각, 2단계 출제(또는 완료)는 DB 함수 하나로 한 번에 처리한다.
   - 근거 없음 (대기 시간 판단). 다른 안은 제출만 받고 채점은 뒤에서 처리하는 방식인데, 예약·작업 큐 장치가 없다.
2. **2단계 출제 규칙**
   - 추천: 1단계와 같은 규칙을 고난이도 문제에 적용한다 (안 본 변형 우선, 순서도 같음).
   - 통과했지만 승인된 고난이도 문제가 없는 항목은 "기본 이해 + 심화 측정 안 함"으로 표시한다. `docs/SCORING.md` 3절에 이 경우가 없으므로 정해야 한다.
3. **리포트 작성 시점**
   - 추천: 진단이 끝나는 순간(2단계 제출, 또는 2단계 없이 끝날 때) 리포트 AI를 바로 부른다.
   - 실패하면 진단은 완료로 두고, 리포트 화면을 열 때 다시 만든다.
4. **2단계 도중 중단 시 리포트** (F-06 "2단계 도중 중단되면 … 리포트를 만든다")
   - 지금 3일 자동 중단은 요청 때 DB 함수로 처리해서, 그 자리에서 AI를 부를 수 없다.
   - 추천: 중단된 진단의 리포트는 학생이 그 진단을 처음 열 때 만든다 (3번과 같은 "없으면 열 때 만든다" 규칙).
   - 1단계 도중 중단은 리포트를 만들지 않는다 (F-06).
5. **개념 데이터 출처**
   - 채점·리포트에 쓰는 문제, 채점 요소, 오개념은 DB에서 읽는다.
   - 리포트 프롬프트가 쓰는 "아직 배우지 않은 용어"(`not_yet_learned`)는 DB에 없고 `backend/data/concepts/*.json`에만 있다.
   - 추천: 이번에는 JSON에서 읽는다 (문제 생성도 지금 그렇게 한다). DB로 옮기는 일은 용어 검증 방식 결정(`docs/PROGRESS.md` 결정 대기)과 함께 한다.
6. **E2E에서 실제 AI를 부르지 않는 방법**
   - 로그인 흐름 E2E가 제출까지 가면 백엔드가 채점·리포트 AI를 부른다. `AGENTS.md` 5.4 예외는 실제 AI를 금지한다.
   - 추천: 백엔드 설정 `AI_MODE`(기본 `real`)를 두고, `pnpm test:e2e:dev`만 백엔드를 `AI_MODE=fake`로 띄운다.
     - 가짜 AI는 정해진 채점 결과와 리포트 문장을 돌려준다.
     - 운영에서 `fake`로 켜지지 않게, `fake`일 때 서버 시작 로그에 경고를 남긴다.
   - 실제 AI는 8단계에서 비용 승인을 받고 한 번 확인한다.
7. **AI 호출 제한**
   - 진단 한 번에 AI 호출은 최대 3번이다 (1·2단계 서술형 채점 각 1, 리포트 1). 약 $0.01이다.
   - 추천: 지금은 개발·테스트 계정만 쓰므로(`AGENTS.md` 4.3, F-11 전) 사용자별 제한을 두지 않는다. "실제 학생 공개 전 필수 항목"에 "AI 호출 제한"을 올린다.
8. **결과 화면 범위**
   - 추천: 진단이 끝나면 같은 주소(`/diagnoses/[id]`)에서 리포트를 보여 준다.
     - 리포트: 개념별 단계, 이해하지 못한 부분, 추정 오개념, 다음 학습 방향
     - 문제별 결과: 맞음/틀림, 내 답, 해설
   - 문제별 결과는 F-10 완료 조건("문제, 답안, 채점 결과, 리포트를 본다")의 상세 화면에 해당한다. 데이터가 이미 있어 같이 만든다. 목록 화면은 다음 계획이다.
