## 이전 계획에서 이어받은 것 (출처: plans/2026-11-11_units-1-1-2.md 인계)
- 단원 절차: 개념 데이터 초안(원문 + 출처) → 승인 → JSON·`load-curriculum` → 생성 → 백로그 처리 → 에이전트 전수 검토 → 승인 → `export` 커밋.
- **반복 원인 대책 문구를 개념 데이터 초안에 처음부터 넣는다** (재생성 비용을 줄인다).
  - 오개념 판별 항목 근거: "오답 보기 하나에는 오개념 하나만 드러나게 한다".
  - 성질 적용 항목 근거: "고난이도도 학생이 직접 계산·비교해 답을 구한다. 풀이를 다 주고 틀린 단계나 법칙 이름만 고르게 하지 않는다".
  - 이유 설명 항목 근거
    - "구체적인 수나 도형·자료로 설명한다. 그 단원에서 아직 배우지 않은 문자 일반화·증명은 요구하지 않는다".
    - 문제 문장이 답을 미리 드러내지 않게 한다.
  - 오개념 문구는 글자 그대로 읽어도 다른 오개념과 겹치지 않게 쓴다.
- v7 검사는 오개념 연결 오류를 안정적으로 잡지 못한다. 에이전트가 승인 전에 정답·오개념 연결·범위를 전부 확인한다 (사용자 결정 2026-11-11).

- 사용자는 수학 교육 전문가가 아니다. 근거가 약한 내용은 "전문가 검토 필요"로 표시한다.
- 도형 단원(`9수03`)은 처음이다.
  - 문제는 글과 KaTeX 수식만 쓸 수 있고 그림을 넣을 수 없다 (`docs/DESIGN.md` "문제 하나에 담는 정보").
  - 그래서 그림 없이 풀 수 있는 문제만 만들게 해야 한다 (결정 4).
- 머지 전 비밀값 검사는 Python 정규식으로 따로 실행한다. 이 PC의 `grep`은 복잡한 패턴에서 오류를 내고, 검사하지 않은 채 끝난 적이 있다 (2026-11-11).

## 결정 사항 (사용자 결정, 2026-11-11: "추천대로 진행하자")
결정 1~4의 추천안을 채택한다: 계획 비용 상한 $9 사전 승인, 개념 데이터 두 묶음 승인, 짚은 문제만 사용자 확인, 그림 없는 도형 문제.

1. **비용 상한 (계획 단위 사전 승인)**
   - 추천: **이 계획 전체의 실제 AI 비용 상한 $9.**
     - 추정 $6.3에 재생성·도형 단원 불확실성으로 약 40%를 더했다. 남은 예산 $26.56의 약 1/3이다.
     - 상한 안에서는 단원마다 다시 묻지 않고 `generate`와 백로그·거부 자리 재생성을 실행한다. 실행할 때마다 실제 비용과 누적액을 보고한다.
     - 누적이 $9에 닿으면 멈추고 다시 승인받는다.
     - 성취기준마다 `--max-cost-usd`는 그 성취기준 추정의 2배로 건다.
2. **개념 데이터 승인 단위**
   - 추천: **묶음 A(7개)와 묶음 B(8개)를 두 번에 나눠 승인받는다.** 묶음 A를 생성·검토하는 동안 묶음 B 초안을 쓴다.
   - 다른 안: 15개를 한 번에 승인받는다 (대기는 1회지만 검토 부담이 크다).
3. **문제 승인 방식**
   - 추천: **에이전트가 전부 검토하고, 짚을 점이 없는 문제는 바로 `master`로 승인한다. 짚은 문제만 사용자에게 보여 거부·승인을 받는다.** 승인 결과(수, 짚은 문제, 거부 이유)는 단원마다 보고한다.
     - 근거: 이전 두 계획에서 사용자는 에이전트가 짚은 문제 외에는 추가로 거부하지 않았다 (중1 3단원 84개, 중1 1·2단원 92개).
     - 사용자 수동 확인(실제로 진단을 풀어 봄)에서 찾은 문제(답이 문장에 드러난 문제 1건)는 계속 사용자 확인으로 잡는다.
   - 다른 안: 지금처럼 모든 승인을 사용자에게 받는다.
4. **도형 단원: 그림 없는 문제**
   - 추천: 개념 데이터 범위에 다음 문장을 넣는다. "그림 없이 글과 기호(예: `∠ABC`, `\overline{AB}`, 좌표)만으로 조건이 모두 주어지는 문제만 낸다. 작도는 순서와 도구의 쓰임을 글로 묻는다."
   - 그림이 꼭 필요한 평가 항목은 이번에 빼고 PROGRESS에 "그림 지원 필요"로 남긴다.
   - 다른 안: 문제에 그림(SVG 등)을 넣는 기능을 먼저 만든다 (코드·설계 작업이 커져 이번 범위 밖).
