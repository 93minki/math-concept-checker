- 생성 전에 최소 호출 하나로 API 키가 동작하는지 확인한다. 동시 생성은 3~4개로 한다 (8개 이하). 성취기준별 비용 상한은 빈자리 × $0.03 이상으로 걸고, 끝난 뒤 빈자리를 개념 데이터 기준으로 다시 센다. (출처: plans/2026-11-11_grade2.md)
- 에이전트가 모든 문제의 정답·오개념 연결·범위를 확인하고, 짚을 점이 없는 문제는 `master`로 승인한다. 짚은 문제만 사용자에게 보인다. 명백한 결함은 사용 중지 후 다시 만든다. (출처: `docs/DESIGN.md` "문제 상태", plans/2026-11-11_grade2.md)
- 교육과정 PDF는 `pdftotext -layout`으로 찾고, 수식 이미지는 PDF 쪽을 이미지로 본다. 쪽수는 PDF 쪽 번호다. (출처: plans/2026-11-11_grade2.md)
- 사용자는 수학 교육 전문가가 아니다. 근거가 약한 내용은 "전문가 검토 필요"로 표시한다.
- 머지 전 비밀값 검사는 Python 정규식으로 한다.

2. **개념 데이터 승인 단위**: 묶음 A(6개), 묶음 B(5개), 묶음 C(시험 2개) 세 번.
3. **문제 승인 방식**: 중2 계획과 같다 (에이전트 전수 검토, 짚은 문제만 사용자).
4. **자료 단원(상자그림·산점도)의 그림 없는 표현** (근거 없음, 에이전트 제안)
   - 상자그림(`9수04-08`)은 그림 대신 다섯 수치(최솟값, 제1사분위수, 중앙값, 제3사분위수, 최댓값)를 표나 글로 주고, 두 집단의 분포 비교를 묻는다. 학생이 상자그림을 그리게 하지 않는다.
   - 산점도(`9수04-09`)는 두 변량의 순서쌍 표나 글 설명(점들이 오른쪽 위로 모여 있음 등)으로 주고, 상관관계(양·음·없음)를 묻는다.
   - 그림을 직접 읽거나 그리는 것은 묻지 못한다 (그림 지원 필요로 센다).
5. **시험 생성(묶음 C) 방식**
