# [9수04-05] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 경우의 수를 구할 수 있다.
- 영역·주제: 자료와 가능성 · 경우의 수와 확률
- 표시 단원: 중2 8 경우의 수와 확률 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 46쪽(성취기준), 47쪽 해설 "경우의 수는 두 경우의 수를 합하거나 곱하는 경우 정도로만 다루고, 순열과 조합을 이용하면 쉽게 해결되는 등의 복잡한 경우의 수를 구하는 문제는 다루지 않는다." 48쪽 "'경우의 수' 용어는 교수⋅학습 상황에서 사용할 수 있다".
- 범위 (에이전트 추론, 전문가 검토 필요): 사건과 경우의 수, 두 사건이 동시에 일어나지 않을 때 경우의 수를 더하는 것, 두 사건이 동시에(잇달아) 일어날 때 경우의 수를 곱하는 것. 해설에 따라 "두 경우의 수를 합하거나 곱하는 경우 정도"만 다루고, 순열·조합으로 풀 문제(여러 명을 한 줄로 세우기, 대표 여러 명 뽑기 등)는 내지 않는다. "합의 법칙", "곱의 법칙", "순열", "조합", "수형도"라는 말은 용어 목록에 없으므로 쓰지 않는다. 나뭇가지 그림 대신 경우를 순서쌍 목록이나 표로 글로 나타낸다. "경우의 수"는 수업용 용어라 문제·해설에 쓰지만 그 뜻 자체를 묻지 않는다.

## 대표 오개념
