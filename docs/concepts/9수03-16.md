# [9수03-16] 개념 데이터

- 상태: 사용자 승인 (2026-11-12)
- 성취기준: 삼각비의 뜻을 알고, 간단한 삼각비의 값을 구할 수 있다.
- 영역·주제: 도형과 측정 · 삼각비
- 표시 단원: 중3 5 삼각비 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 44쪽(성취기준), 45쪽 용어 "삼각비, 사인, 코사인, 탄젠트, sin, cos, tan", 46쪽 고려 사항 "삼각비 사이의 관계는 다루지 않는다", "삼각비의 값은 0°에서 90°까지의 각도에 대한 것만 다룬다".
- 변경: 2026-11-12 (사용자 승인 "109개 항목 승인할게") 그림 확장 계획에서 평가 항목 3개를 그림 항목으로 바꿈 (`docs/DESIGN.md` "그림 확장")
- 범위 (에이전트 추론, 전문가 검토 필요): 직각삼각형에서 한 예각에 대한 사인·코사인·탄젠트의 뜻, 세 변의 길이로 삼각비의 값 구하기(필요하면 피타고라스 정리로 나머지 변을 구함), 30°, 45°, 60°의 삼각비의 값, 0°와 90°의 삼각비의 값. 삼각비 사이의 관계(예: `\sin^2 A + \cos^2 A = 1`, `\tan A = \frac{\sin A}{\cos A}`)는 다루지 않는다 (PDF 46쪽). 둔각의 삼각비는 다루지 않는다. 그림 평가 항목(아래 "그림" 문장에 적은 항목)이 아닌 평가 항목은 그림 없이 글과 기호(예: `∠ABC`, `\overline{AB}`, `△ABC`, 좌표)만으로 조건이 모두 주어지는 문제만 낸다 (`docs/DESIGN.md` "그림 없음"). 점의 위치는 글로 모두 정해 주고, 그림을 보아야만 알 수 있는 조건을 남기지 않는다. "가정", "결론" 용어는 쓰지 않는다 (PDF 46쪽). 직각삼각형은 "∠C = 90°인 직각삼각형 ABC에서 `\overline{AB} = 5`, `\overline{BC} = 3`"처럼 직각의 위치와 변의 길이를 글로 모두 준다. 그림 (사용자 승인 2026-11-12, 그림 확장 계획): 이 성취기준의 그림 평가 항목(C1-정의이해, C1-오개념판별, C1-이유설명)은 정해진 그림(본문 또는 보기)을 반드시 넣고, 이 범위의 "그림 없이·글로 준다" 문장을 적용하지 않는다. 그림과 본문·해설이 서로 맞게 한다.
