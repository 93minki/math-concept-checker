# [9수02-08] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 지수법칙을 이해하고, 이를 이용하여 식을 간단히 할 수 있다.
- 영역·주제: 변화와 관계 · 식의 계산
- 표시 단원: 중2 2 식의 계산 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 41쪽(성취기준), 42쪽 해설 "지수법칙은 지수가 자연수인 범위에서 단항식의 곱셈과 나눗셈을 하는 데 필요한 정도로 다룬다." 43쪽 고려 사항 "수에 대한 사칙연산과 소인수분해가 다항식으로 확장될 수 있음을 인식하게 한다".
- 변경: 2026-11-11 생성 백로그·검토 결과로 근거·범위를 보강함 (사용자 승인). 오개념 판별 근거에 조합 보기 금지와 "잘못된 까닭" 문제의 오개념 연결 규칙 추가
- 범위 (에이전트 추론, 전문가 검토 필요): 지수가 자연수인 지수법칙 다섯 가지: `a^m \times a^n = a^{m+n}`, `(a^m)^n = a^{mn}`, `a^m \div a^n` (m > n이면 `a^{m-n}`, m = n이면 `1`, m < n이면 `\frac{1}{a^{n-m}}`), `(ab)^n = a^n b^n`, `\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}`. 지수가 0이나 음수인 거듭제곱(`a^0`, `a^{-1}`)은 쓰지 않는다. 단항식의 곱셈과 나눗셈(계수 포함, 부호 포함, 세 개까지)을 다룬다. 단항식과 다항식의 곱셈·나눗셈은 [9수02-10]에서 다룬다.
