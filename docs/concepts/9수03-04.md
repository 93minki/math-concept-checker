# [9수03-04] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 삼각형의 합동 조건을 이해하고, 이를 이용하여 두 삼각형이 합동인지 판별할 수 있다.
- 영역·주제: 도형과 측정 · 작도와 합동
- 표시 단원: 중1 5 기본 도형과 작도 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 43쪽(성취기준), 45쪽 고려 사항 "다양한 교구나 공학 도구를 이용하여 합동과 닮음의 의미를 이해하게 한다."
- 변경: 2026-11-12 (사용자 승인 "109개 항목 승인할게") 그림 확장 계획에서 평가 항목 4개를 그림 항목으로 바꿈 (`docs/DESIGN.md` "그림 확장")
- 범위 (에이전트 추론, 전문가 검토 필요): 합동의 뜻과 기호 `≡`, 대응점·대응변·대응각, 삼각형의 합동 조건(SSS, SAS, ASA). 근거 끝에 `[그림: …]`이 없는 평가 항목은 그림 없이 글과 기호(예: `∠ABC`, `\overline{AB}`, `△ABC`, 좌표)만으로 조건이 모두 주어지는 문제만 낸다 (사용자 결정 2026-11-11, 이 계획 결정 4). 두 삼각형의 변의 길이와 각의 크기는 `\overline{AB} = 5`, `∠B = 40°`처럼 글로 준다. "가정", "결론" 용어는 쓰지 않는다 (PDF 46쪽). 그림 (사용자 승인 2026-11-12, 그림 확장 계획): 근거 끝에 `[그림: …]`이 있는 평가 항목(C1-정의이해, C2-성질적용, C2-오개념판별, C2-이유설명)은 그 그림을 넣고, 이 범위의 "그림 없이·글로 준다" 문장을 적용하지 않는다. 그림과 본문·해설이 서로 맞게 한다.
