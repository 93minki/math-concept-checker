# [9수01-10] 개념 데이터

- 상태: 사용자 승인 (2026-11-12)
- 성취기준: 근호를 포함한 식의 사칙계산의 원리를 이해하고, 그 계산을 할 수 있다.
- 영역·주제: 수와 연산 · 제곱근과 실수
- 표시 단원: 중3 1 제곱근과 실수 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 39쪽(성취기준), 40쪽 용어 "분모의 유리화", 고려 사항 "정수, 유리수와 관련하여 지나치게 복잡한 계산을 포함하는 문제는 다루지 않는다". 이 성취기준의 "성취기준 해설"은 원문에 없다.
- 범위 (에이전트 추론, 전문가 검토 필요): 제곱근의 곱셈과 나눗셈(`\sqrt{a}\sqrt{b} = \sqrt{ab}`, `\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}`, a > 0, b > 0), 근호 안의 수에 들어 있는 어떤 수의 제곱을 근호 밖으로 꺼내거나 근호 안으로 넣기(`\sqrt{12} = \sqrt{2^2 \times 3} = 2\sqrt{3}`), 분모의 유리화(분모가 `\sqrt{a}` 또는 `b\sqrt{a}` 꼴), 근호를 포함한 식의 덧셈과 뺄셈(근호 안의 수가 같은 것끼리), 분배법칙을 이용한 간단한 혼합 계산. 분모가 `a+\sqrt{b}` 꼴인 유리화는 곱셈 공식([9수02-19], 뒤 단원)이 필요하므로 다루지 않는다. 근호 안의 수는 200 이하의 자연수로 하고 계산 단계는 3단계 이내로 한다 ("지나치게 복잡한 계산" 제외, 기준은 에이전트 추론).
