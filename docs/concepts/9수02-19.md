# [9수02-19] 개념 데이터

- 상태: 사용자 승인 (2026-11-12)
- 성취기준: 다항식의 곱셈과 인수분해를 할 수 있다.
- 영역·주제: 변화와 관계 · 다항식의 곱셈과 인수분해
- 표시 단원: 중3 2 다항식의 곱셈과 인수분해 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 41쪽(성취기준), 42쪽 해설 "다항식의 곱셈과 다항식의 인수분해의 역관계를 이해하고, 이와 유사한 관계를 찾아보는 활동을 하게 한다. 다항식의 곱셈과 인수분해는 다음의 경우를 다룬다. `m(a+b) = ma+mb`, `(a+b)^2 = a^2+2ab+b^2`, `(a-b)^2 = a^2-2ab+b^2`, `(a+b)(a-b) = a^2-b^2`, `(x+a)(x+b) = x^2+(a+b)x+ab`, `(ax+b)(cx+d) = acx^2+(ad+bc)x+bd`" (수식은 PDF 42쪽 이미지로 확인), 43쪽 "'이차식', '전개식' 용어는 교수⋅학습 상황에서 사용할 수 있다".
- 범위 (에이전트 추론, 전문가 검토 필요): 해설의 여섯 가지 꼴의 곱셈(전개)과 인수분해(공통인수로 묶기 포함). 계수는 절댓값 20 이하의 정수, 인수분해할 식은 문자 하나 또는 둘. 인수분해는 끝까지(더 인수분해할 수 없을 때까지) 한다. 세제곱이 나오는 곱셈 공식, 복잡한 치환은 다루지 않는다. 이차방정식 풀이는 [9수02-20](뒤 단원)에서 다룬다.
