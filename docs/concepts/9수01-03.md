- 영역·주제: 수와 연산 · 정수와 유리수
- 표시 단원: 중1 2 정수와 유리수 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"

## 대표 오개념

| ID | 개념 | 오개념 | 출처 |
|---|---|---|---|
| M1 | C2 | 분수 꼴로 쓰인 수만 유리수라고 보고, 정수나 소수(예: `0.5`)는 유리수가 아니라고 생각한다. | 출처 확인 못 함 — 전문가 검토 필요 |
| M2 | C2 | 0을 양수(또는 음수)로 분류한다. | 출처 확인 못 함 — 전문가 검토 필요 |
| M3 | C1 | 수 앞의 `-`를 "빼기"로만 읽어, `-3`을 "무엇에서 3을 뺀 것"으로 생각하고 하나의 수(음수)로 보지 못한다. | [Vlassis (2004), Learning and Instruction 14, 469–484](https://doi.org/10.1016/j.learninstruc.2004.06.012) (마이너스 기호의 여러 뜻을 구별하는 어려움, 서지 확인). 이 사례는 에이전트 예시 — 전문가 검토 필요 |
| M4 | C1, C2 | `-`가 붙어 있으면 언제나 음수라고 생각한다. `-(-3)`을 음수로 본다. | [Vlassis (2004), Learning and Instruction 14, 469–484](https://doi.org/10.1016/j.learninstruc.2004.06.012) (마이너스 기호의 여러 뜻을 구별하는 어려움, 서지 확인). 이 사례는 에이전트 예시 — 전문가 검토 필요 |
