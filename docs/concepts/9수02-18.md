# [9수02-18] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 두 일차함수의 그래프와 연립일차방정식의 관계를 설명할 수 있다.
- 영역·주제: 변화와 관계 · 일차함수와 일차방정식의 관계
- 표시 단원: 중2 4 일차함수와 그래프 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 41쪽(성취기준), 43쪽 고려 사항 "다양한 상황을 일상 언어, 표, 그래프, 식으로 나타내고 이들 사이의 상호 변환 활동을 하게 한다", "'연립일차방정식'… 용어는 교수⋅학습 상황에서 사용할 수 있다". 이 성취기준의 "성취기준 해설"은 원문에 없다.
- 변경: 2026-11-11 범위의 그래프 문구를 "그래프를 묻는 보기는 글로 쓰고, 식·수를 고르는 보기와 서술형도 쓸 수 있다"로 고침. 검사가 모든 보기를 그래프 설명으로 써야 한다고 읽어 백로그가 생김 (사용자 승인)
- 범위 (에이전트 추론, 전문가 검토 필요): 연립일차방정식의 해와 두 일차함수 그래프의 교점의 좌표, 해의 개수(하나, 없음, 무수히 많음)와 두 그래프의 위치 관계(한 점에서 만남, 평행, 일치). 해가 없거나 무수히 많은 연립방정식은 이 성취기준에서 다룬다 ([9수02-13]에서 뺐다). 그림을 넣을 수 없으므로 그림 없이 글과 기호(예: 좌표)만으로 조건이 모두 주어지는 문제만 낸다. 그래프는 식, 지나는 점의 좌표, 표, 글 설명(기울기의 부호, x절편·y절편, 지나는 사분면)으로 준다. 학생이 그래프를 그리게 하지 않는다. 그래프의 모양·위치를 묻는 보기는 글로 쓴다. 식이나 수를 고르는 보기와 서술형도 쓸 수 있다 (사용자 결정 2026-11-11, 이 계획 결정 4). 두 그래프를 그려 교점을 눈으로 읽는 풀이는 묻지 못한다 (그림 지원 필요, PROGRESS).
