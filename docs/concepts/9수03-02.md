# [9수03-02] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 평행선에서 동위각과 엇각의 성질을 이해하고 설명할 수 있다.
- 영역·주제: 도형과 측정 · 기본 도형
- 표시 단원: 중1 5 기본 도형과 작도 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 43쪽(성취기준). 이 성취기준의 "성취기준 해설"은 원문에 없다.
- 범위 (에이전트 추론, 전문가 검토 필요): 두 직선이 한 직선과 만날 때 생기는 동위각·엇각, 평행선에서 동위각·엇각의 크기가 같다는 성질과 그 역(동위각 또는 엇각이 같으면 평행). 그림을 넣을 수 없으므로 그림 없이 글과 기호(예: `∠ABC`, `\overline{AB}`, `△ABC`, 좌표)만으로 조건이 모두 주어지는 문제만 낸다 (사용자 결정 2026-11-11, 이 계획 결정 4). 각의 위치는 "직선 n이 두 직선 l, m과 각각 점 P, Q에서 만난다. ∠a는 점 P에서 직선 n의 오른쪽 위에 있는 각, ∠b는 점 Q에서 직선 n의 오른쪽 위에 있는 각"처럼 글로 정해 준다. 그림 없이 위치를 찾는 것만 묻는 문제는 내지 않는다 (그림 지원 필요, PROGRESS).
