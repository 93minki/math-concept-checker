# [9수03-06] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 부채꼴의 중심각과 호의 관계를 이해하고, 이를 이용하여 부채꼴의 호의 길이와 넓이를 구할 수 있다.
- 영역·주제: 도형과 측정 · 평면도형의 성질
- 표시 단원: 중1 6 평면도형의 성질 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 43쪽(성취기준). 이 성취기준의 "성취기준 해설"은 원문에 없다.
- 범위 (에이전트 추론, 전문가 검토 필요): 한 원에서 중심각의 크기와 호의 길이·부채꼴의 넓이의 정비례 관계(현의 길이는 정비례하지 않음), 부채꼴의 호의 길이와 넓이(원주율은 π). 그림을 넣을 수 없으므로 그림 없이 글과 기호만으로 조건이 모두 주어지는 문제만 낸다 (사용자 결정 2026-11-11).
