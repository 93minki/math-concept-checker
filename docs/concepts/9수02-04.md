# [9수02-04] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 일차방정식을 풀 수 있고, 이를 활용하여 문제를 해결할 수 있다.
- 영역·주제: 변화와 관계 · 일차방정식
- 표시 단원: 중1 3 문자의 사용과 식 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 원문 근거: 교육과정 PDF 40쪽(성취기준). 43쪽 고려 사항 "방정식과 부등식은 여러 가지 방법으로 풀어 보면서 더 나은 풀이 방법으로 해를 찾게 한다. 구한 해가 문제 상황에 적합한지 확인하는 과정을 통해…", "방정식, 부등식, 함수에 대한 지나치게 복잡한 활용 문제는 다루지 않는다". 이 성취기준의 "성취기준 해설"은 원문에 없다.
- 범위 (에이전트 추론, 전문가 검토 필요): 미지수가 하나이고 해가 하나인 일차방정식. 계수와 상수항에 정수·분수·소수, 괄호가 있어도 된다. 해가 없거나 무수히 많은 경우는 다루지 않는다. 활용은 수, 개수, 나이, 가격, 간단한 거리·속력·시간처럼 한 가지 관계로 식을 세우는 상황만 다룬다 ("지나치게 복잡한 활용 문제는 다루지 않는다", PDF 43쪽). 미지수가 2개인 방정식([9수02-13])과 부등식([9수02-11])은 쓰지 않는다.

|---|---|---|---|
| M1 | C2 | 분모를 없앨 때 일부 항에만 수를 곱한다. `x/2 + 1 = 3`의 양변에 2를 곱하면서 `x + 1 = 6`으로 쓴다. | 출처 확인 못 함 — 전문가 검토 필요. 후보: 방승진·심현영(2009) 「일차방정식 풀이에서의 오류와 지도 방안」, 교과교육연구 2(2) (원문 미확인) |
