# [9수01-05] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 정수와 유리수의 사칙계산의 원리를 이해하고, 그 계산을 할 수 있다.
- 영역·주제: 수와 연산 · 정수와 유리수
- 표시 단원: 중1 2 정수와 유리수 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05, 사용자 결정 2026-11-11)
- 원문 근거: 교육과정 PDF 39쪽 성취기준 해설 "정수의 사칙계산의 원리는 여러 가지 모델을 이용하여 직관적으로 이해하게 하고, 실생활에서 사칙계산의 유용성을 인식하게 한다." 40쪽 고려 사항 "정수, 유리수와 관련하여 지나치게 복잡한 계산을 포함하는 문제는 다루지 않는다", "사칙계산 이외의 이항연산 문제는 다루지 않는다".
- 범위 (에이전트 추론, 전문가 검토 필요): 정수와 유리수(분수, 소수)의 덧셈·뺄셈·곱셈·나눗셈과 혼합 계산, 거듭제곱이 섞인 계산. 교환법칙·결합법칙·분배법칙을 이용한 계산. 지나치게 복잡한 계산과 사칙계산이 아닌 새 연산(예: `a ⊙ b = …`)은 쓰지 않는다 (PDF 40쪽).
