# [9수02-02] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 일차식의 덧셈과 뺄셈의 원리를 이해하고, 그 계산을 할 수 있다.
- 영역·주제: 변화와 관계 · 문자의 사용과 식
- 표시 단원: 중1 3 문자의 사용과 식 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 원문 근거: 교육과정 PDF 40쪽(성취기준), 43쪽 고려 사항 "수에 대한 사칙연산과 소인수분해가 다항식으로 확장될 수 있음을 인식하게 한다". 이 성취기준의 "성취기준 해설"은 원문에 없다.
- 변경: 2026-11-11 `9수02-02-C3-이유설명` 근거를 구체화함. 문제 생성에서 검사 AI가 의도와 다른 문제를 거절해 백로그가 됨 (사용자 승인)
- 범위 (에이전트 추론, 전문가 검토 필요): 일차식(문자가 하나 또는 둘, 각 문자의 차수 1)의 덧셈과 뺄셈. 괄호를 푸는 데 필요한 "수 × 일차식", "일차식 ÷ 수"(분배법칙, 예: `2(x+3) - (x-1)`)는 다룬다. 일차식끼리의 곱셈과 차수가 2 이상인 다항식의 계산은 [9수02-09]·[9수02-10]·[9수02-19](중2·중3)에서 다루므로 쓰지 않는다.

## 대표 오개념

| ID | 개념 | 오개념 | 출처 |
|---|---|---|---|
| M1 | C2, C3 | 동류항이 아닌 항을 하나로 합친다. `2a + 3b`를 `5ab`로, `3x + 2`를 `5x`로 쓴다. 식을 하나의 "답"으로 끝내려는 경향과 관련된다. | [Falle (2007), MERGA 30 학술대회 발표 논문](https://merga.net.au/wp-content/uploads/DOCS/common/Uploaded%20files/Annual%20Conference%20Proceedings/2007%20Annual%20Conference%20Proceedings/RP232007%20falle.pdf) (Booth 1984·1988 인용, 2차 문헌으로 확인) |
| M2 | C3 | 괄호 앞의 `-`를 첫째 항에만 적용한다. `-(2x - 3)`을 `-2x - 3`으로 쓴다. | 관련 연구: [Vlassis (2004), Learning and Instruction 14, 469–484](https://doi.org/10.1016/j.learninstruc.2004.06.012) (마이너스 기호 해석의 어려움, 서지 확인). 이 사례는 에이전트 예시 — 전문가 검토 필요 |
| M3 | C1 | 계수를 찾을 때 부호를 빼거나, 문자 앞에 수가 없으면 계수가 없다고 본다. `-3x`의 계수를 `3`, `x`의 계수를 `0`이라고 한다. | 출처 확인 못 함 — 전문가 검토 필요 |
| M4 | C1 | 차수와 계수를 혼동한다. `5x`의 차수를 `5`라고 하거나, 항의 개수로 일차식인지 판단한다. | 출처 확인 못 함 — 전문가 검토 필요 |
