# [9수02-07] 개념 데이터

- 상태: 사용자 승인 (2026-11-11)
- 성취기준: 정비례, 반비례 관계를 이해하고, 그 관계를 표, 식, 그래프로 나타낼 수 있다.
- 영역·주제: 변화와 관계 · 좌표평면과 그래프
- 표시 단원: 중1 4 좌표평면과 그래프 (동아출판 기준)
- 형식: `docs/DESIGN.md` "개념 데이터 (F-03)"
- 변형 수: 2 (`docs/features.md` F-05)
- 원문 근거: 교육과정 PDF 40쪽(성취기준), 42쪽 해설 "속력과 거리, 속력과 시간과 같은 실생활의 예를 통해 정비례와 반비례 관계를 직관적으로 이해하게 하고, 정비례와 반비례 관계가 성립하는 실생활의 예를 찾아 설명하게 한다."
- 범위 (에이전트 추론, 전문가 검토 필요): 정비례 `y = ax`, 반비례 `y = a/x` (a는 0이 아닌 수). 표와 식, 그래프의 특징은 글로 다룬다(정비례는 원점을 지나는 직선, 반비례는 좌표축에 한없이 가까워지는 한 쌍의 매끄러운 곡선). 그림을 넣을 수 없으므로 그림 없이 글과 기호(예: `∠ABC`, `\overline{AB}`, `△ABC`, 좌표)만으로 조건이 모두 주어지는 문제만 낸다 (사용자 결정 2026-11-11, 이 계획 결정 4). "함수", "변수"라는 말은 쓰지 않는다(뒤 단원 용어).
