## 시작 전에 사용자와 정할 것 (그림과 기존 결정이 부딪히는 곳)
- **샘플 리포트의 "단원 이해도 70%"**: 리포트는 숫자 없이 단계만 보인다 (`docs/SCORING.md` 5절, `DESIGN.md` "리포트 표시"). 넣지 않는 쪽이 기존 결정과 맞다.
- **"무료로 시작하기"**: 요금 정책이 정해진 적이 없다. 문구를 "지금 시작하기" 등으로 바꿀지.
- **그림(노트북 속 화면, 개념이 3D 느낌, 책, 리포트 아이콘)**: 래스터 그림 파일을 만들 도구가 없다. SVG·CSS로 비슷하게 그릴지, 사용자가 그림 파일을 줄지.
- 단계 칩 이름: 그림은 "아직 미이해", 서비스는 "아직 이해 못 함" (`SCORING.md`). 서비스 이름을 따른다.
